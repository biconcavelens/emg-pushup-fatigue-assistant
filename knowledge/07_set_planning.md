# Planning sets: examples of coaching decisions

Example plan for push-ups, three sets, aiming at quality: set 1 ends at about 20 % tempo loss (reps in reserve about 2 to 3); rest 2 minutes; set 2 repeats the same target; set 3 can go closer to failure if form stays good.

If set 1 went to failure with 30 or more reps and 40 % or more tempo loss: next time stop earlier, around 20 to 25 % tempo loss, and rest at least 2 to 3 minutes before set 2 because failure sets leave more residual fatigue.

If set 2 has fewer than about 70 % of set 1's reps: incomplete recovery; lengthen the rest by 1 minute or reduce the target reps.

If tempo loss stays under 10 % at the planned rep count: the set is too easy; add reps, slow the tempo, or use a harder variation.

If EMG amplitude rises steeply (more than about 50 % versus the first reps) while tempo is still fine: fatigue is building underneath; expect tempo loss soon and consider ending the set.

If amplitude falls while reps stall: probable exhaustion; end the set and rest.
